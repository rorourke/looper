# Project Instructions

- After making user-visible changes to the Electron app, rebuild and reopen the packaged app with `./script/build_and_run.sh` so the user can see the changes immediately.
- After making changes to Looper, deploy them to production at `looper.app` before handing the work back to the user. Do not leave completed changes only in the local workspace unless the user explicitly asks for local-only work or we are actively testing the change locally.
