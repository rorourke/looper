# Looper Electron app

This directory contains Looper’s Electron main process, secure preload bridge, React interface, calculation engine, tests, and packaging configuration.

See the repository [README](../README.md) for product behavior and setup, [CONTRIBUTING.md](../CONTRIBUTING.md) for the development workflow, and [docs/macos-distribution.md](../docs/macos-distribution.md) for signed macOS releases.

Common commands:

```sh
pnpm dev
pnpm test
pnpm typecheck
pnpm build
```
