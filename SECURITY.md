# Security

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email [ryano@hey.com](mailto:ryano@hey.com) with:

- the affected Looper version and operating system;
- a clear description of the issue and its impact;
- reproducible steps or a proof of concept; and
- any suggested mitigation, if you have one.

Do not include real credentials, private `.loop` files, or unrelated personal data. You should receive an acknowledgment within seven days. Please allow time for a fix and release before publishing details.

## Supported versions

Security fixes target the latest published Looper release. Install signed updates promptly and download release builds only from [looper.app](https://looper.app/) or the repository’s official release page.

## Product boundary

Looper stores sheets locally and has no account, payment, sharing, or cloud-storage service. Network access is limited to application updates, downloads, and ticker-symbol requests used by live market-price formulas. Public builds compile internal debug access out.
